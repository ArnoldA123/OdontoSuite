## Specs

S1 — #454 badges. `grep -rl "<UiStatusPill" resources/js/modules --include=*.vue`
no devuelve resultados y el eje `badges` del instrumento queda en 0 DIV. No se
tocan los textos de estado de cada dominio.

```console
$ grep -rl "<UiStatusPill" resources/js/modules --include=*.vue   # sin resultados
$ node tests/e2e/audit/u11/report.js --out=.atl/qa-evidence/audit/ui/U11
eje badges: 0 DIV
```

S2 — #452 states. El eje `states` deja DIV sólo en las rutas con aceptación
declarada (`/login`, `/reset-password`, `/:pathMatch(.*)*`) y las seis superficies
medidas publican placeholder de carga visible.

```console
$ node tests/e2e/audit/u11/report.js --out=.atl/qa-evidence/audit/ui/U11
eje states: DIV sólo en las rutas con ACE declarada (login, reset-password, 404)
$ node -e "…leer render/*.json…"   # loadingProbe.skeleton|spinner true en las seis superficies
```

S3 — #455 buttons. El eje `buttons` queda en 0 DIV: el disparador de un alta es
«Nuevo/Nueva <sustantivo>», el envío de un formulario lleva verbo con objeto y
ningún envío se rotula `Aceptar`/`Confirmar`/`OK` a secas.

```console
$ node tests/e2e/audit/u11/report.js --out=.atl/qa-evidence/audit/ui/U11
eje buttons: 0 DIV
$ grep -rn "Registrar \(cargo\|cobro\|depósito\|movimiento\|addendum\|evolución\|caso\)" resources/js/modules --include=*.vue
# sólo en textos de ayuda o mensajes, no en etiquetas de acción
```

S4 — #456 filters. El eje `filters` queda en 0 DIV: toda superficie con filtros
monta `UiFilterBar` y el único verbo de limpieza es «Limpiar filtros»; los
endpoints y sus parámetros no cambian.

```console
$ node tests/e2e/audit/u11/report.js --out=.atl/qa-evidence/audit/ui/U11
eje filters: 0 DIV
$ node -e "…static.json…"   # resetLabels ⊆ {'Limpiar filtros'}
```

S5 — #453 list. El eje `list` queda en 0 DIV: `/patients`, `/professionals`,
`/appointment-types` y `/procedure-catalog` heredan `UiDataTable`, con su
paginación y su affordance de scroll; la fila y las acciones por fila de cada
módulo se conservan.

```console
$ node tests/e2e/audit/u11/report.js --out=.atl/qa-evidence/audit/ui/U11
eje list: 0 DIV
$ node -e "…render/*.json…"   # dataTableScroll 1 y scrollAffordance 1 en las cuatro rutas
```
